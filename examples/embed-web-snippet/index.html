Drop-in Adaptive Cards renderer

Minimum-viable example: one HTML file, one ES module, one ac.wasm binary. No npm step, no bundler, no build process. Drop these four files (index.html, ac-embed.js, ac-host.css, ac.wasm) anywhere your existing web app serves static assets.

The integration

<link rel="stylesheet" href="./ac-host.css">
<div id="my-card"></div>

<script type="module">
  import { loadAdaptiveCards } from "./ac-embed.js";
  const ac = await loadAdaptiveCards("./ac.wasm");
  const cardJSON = await (await fetch("./cards/simple-text.json")).text();
  ac.render(cardJSON, document.getElementById("my-card"), {
    onAction: (action) => console.log("ac:action", action),
  });
</script>

What gets rendered

Every Adaptive Card element comes out as a stable <div data-ac-node="…" class="ac-* …"> shape. The companion stylesheet (ac-host.css) ships reasonable defaults; your app's own CSS can override any class or attribute selector freely.
